# Marco 2 · OCRA

- `consultas/intermediarias`: 30 consultas (≥ 3 tabelas e ≥ 2 de JOIN, GROUP BY, WINDOW, COUNT).
- `consultas/avancadas`: 20 consultas (≥ 3 tabelas e ≥ 3 de subconsulta, JOIN, GROUP BY, WINDOW, COUNT).
- `otimizacao/algebra`: 20 consultas reescritas (≥ 3 técnicas de álgebra relacional).
- `otimizacao/indices`: índices criados para as mesmas 20 consultas.
- `benchmark`: execuções com `EXPLAIN ANALYZE` (≥ 20 por consulta e plano) e resultados.

Cada arquivo de consulta começa com um comentário indicando categoria e requisito(s) atendido(s) (Regra 9).
